# 两步路去广告模块

这是一个Xposed模块，你需要一个框架来启动它，比如LSPosed，安装模块后默认会选中两步路APP，手动在LSPosed里启动模块即可。
以下功能默认全部开启，可按需关闭，设置入口见文末图。

> 因为我丢失了此前的开发密钥无法编译出升级包，因此已安装该模块的用户，可能需要卸载模块，再安装才能成功

## 去广告

1. **隐藏各类广告**：开屏广告、首页信息流广告、多页面轮播横幅广告、资讯列表广告、运动记录页广告、出游详情顶部广告、主界面插屏广告、弹窗广告全部去除，要的就是清爽体验。

## 解锁会员功能
1. **解锁 图片水印**
2. **解锁 DIY首页**：设置启动页入口：APP-我的-设置-更多设置-启动后默认界面：首页/地图主界面
3. **解锁 头像挂件**：更换挂件后可能需要重启一次APP才能完全生效
4. **解锁 专属样式**：记录皮肤、导航皮肤、桌面图标均已可用
5. **解锁 个性化分享**：分享记录-进阶数据

## 分享页功能增强
1. **分享卡片软广净化（两步路的文字、LOGO）**
2. **分享卡文案自定义**：现在你可以长按文案，自己输入想说的内容
3. **隐藏打卡天数**：打卡页的天数支持隐藏（我觉得这个天数真的多余，正常来说打卡分享应该是本次打卡，不要累积历史天数）

## 页面净化

1.  **隐藏"我的"页会员促销横幅**：这样信息密度更高，也更美观
2.  **屏蔽底部 dock 栏图标红点**：屏蔽dock栏【我的】消息数，保留我的页面右上角消息未读数
3.  **隐藏"我的"页顶部 VIP 客服按钮**
4.  **屏蔽升级弹窗**

## 交互优化

1. **装备 tab 防误触**：点击底部 dock 的"装备"会进行拦截弹窗询问，防止误触（是的，这个误触真的很烦人，尤其是他们设计进入的商城还有一个底栏！）




> 注：此版本（及以后）都会使用vibe coding进行编码、构建，人工测试。
