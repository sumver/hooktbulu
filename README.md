# 两步路去广告模块

这是一个Xposed模块，你需要一个框架来启动它，比如LSPosed，安装模块后默认会选中两步路APP。手动在LSPosed里启动模块即可。模块自带设置界面（Material 3），全部功能按分类提供开关（默认全部开启）。

> 因为我丢失了此前的开发密钥无法编译出升级包，因此已安装该模块的用户，可能需要卸载模块，再安装才能成功

1. **隐藏各类广告**：开屏广告、首页信息流广告、多页面轮播横幅广告、资讯列表广告、运动记录页广告、出游详情顶部广告、主界面插屏广告、弹窗广告全部去除，要的就是清爽体验。
2. **隐藏"我的"页会员促销横幅**：这样信息密度更高，也更美观
3. **隐藏"我的"页顶部 VIP 客服按钮**
4. **屏蔽底部 dock 栏图标红点**：屏蔽dock栏【我的】消息数，保留我的页面右上角消息未读数
5. **装备 tab 防误触**：点击底部 dock 的"装备"会进行拦截弹窗询问，防止误触（是的，这个误触真的很烦人，尤其是他们设计进入的商城还有一个底栏！）
6. **屏蔽升级弹窗**：检测到新版本也不会再弹窗打扰你。
7. **解锁五项会员权益的本地门控**：图片水印（拍照水印）、DIY首页（把地图设为启动界面）、头像挂件、记录/导航皮肤、个性化分享（保存带高级数据的分享图、隐藏"加入VIP"横幅）。仅解除客户端的"需要开通会员"拦截，不伪造账号 VIP 状态、不拦截网络请求、不影响购买流程；皮肤/挂件等素材仍由服务端下发。
8. **设置界面（Material 3）**：以上全部功能按分类提供开关，默认全部开启；开关保存后最长约 1 秒内生效（个别页面需退出重进）。

> 注：此版本（及以后）都会使用vibe coding进行编码、构建，人工测试。
