# 两步路去广告（TbuluAdFree）

> 因为我丢失了此前的开发密钥无法编译出升级包，因此已安装该模块的用户，可能需要卸载模块，再安装才能成功

1. **隐藏各类广告**：开屏广告、首页信息流广告、多页面轮播横幅广告、资讯列表广告、运动记录页广告、出游详情顶部广告、主界面插屏广告、弹窗广告全部去除，要的就是清爽体验。
2. **隐藏"我的"页会员促销横幅**：这样信息密度更高，也更美观
3. **隐藏"我的"页顶部 VIP 客服按钮**
4. **屏蔽底部 dock 栏图标红点**：屏蔽dock栏【我的】消息数，保留我的页面右上角消息未读数
5. **装备 tab 防误触**：点击底部 dock 的"装备"会进行拦截弹窗询问，防止误触（是的，这个误触真的很烦人，尤其是他们设计进入的商城还有一个底栏！）

> 注：此版本（及以后）都会使用vibe coding进行编码、构建，人工测试。
